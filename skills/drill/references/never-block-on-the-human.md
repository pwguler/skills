# Never Block on the Human

After a plan is settled and agreed, reversible mid-slice execution choices proceed without re-opening the interview. Present what you did when it matters; do not stall the slice on optional preference calls.

This never overrides the suite's ask-first rules. Always stop and ask for: work on the base branch, land path (merge / PR / keep / discard), discarding work, unsettled forks, and any sketch or shape change that alters the settled spec. Product direction stays with the user; routine execution inside an agreed slice does not wait on them.
