# Encode Lessons in Structure

When the same instruction appears a second time, or the same correction keeps landing, encode the rule as a lint, metadata flag, runtime check, type, or script. Prefer a structural fix alone when it makes the mistake impossible. More prose is the last resort.

If the lesson needs judgment and cannot be encoded, make the existing instruction more prominent and add one concrete example of the failure mode. Do not add a second copy of the same rule in another file.
